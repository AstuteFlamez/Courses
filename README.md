## Repository history

Consolidated from `AstuteFlamez/ece352`, `AstuteFlamez/cs354`, and
`AstuteFlamez/cs400`. Original commits are preserved in the history and
original branches are retained under `archive/<course>/...`.

The 16 CS 400 assignment repositories are included as ordinary folders,
using the exact commits referenced by the original CS 400 repository.
Their commit histories and branches are also preserved under
`archive/cs400/<week>/<assignment>/...`. Original assignment tags and
remote-tracking snapshots are retained as namespaced tags.

The original GitHub repositories are archived as private backups.
