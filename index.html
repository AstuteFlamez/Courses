Red-Black Tree Insertion

A red-black tree is a self-balancing binary search tree. Red-black trees guarantee O(log n) search, insertion, and deletion even in the worst case.

Example of a red-black tree. Image: Wikimedia Commons.

The Red-Black Properties

Every valid red-black tree must satisfy all of these rules:

  • 1. Every node is colored either red or black.
  • 2. The root node is always black.
  • 3. A red node cannot have a red child (no two reds in a row).
  • 4. Every path from a node down to a null leaf passes through the same number of black nodes.

How Insertion Works

Inserting a new value follows these steps:

  1. Insert the new node exactly like a normal binary search tree insertion.
  2. Color the newly inserted node red.
  3. If the new red node's parent is also red, a property is violated and must be fixed.
  4. Look at the "uncle" node: if it is red, recolor the parent, uncle, and grandparent.
  5. If the uncle is black, perform a rotation and recolor.
  6. Finally, always make sure the root is colored black.

Why Rebalancing Matters

  • Keeps the tree's height close to log(n).
  • Requires only a constant number of rotations per insertion.
  • Used in real systems.
